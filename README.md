# SPaRTA: Spatial Reasoning in Text-to-SQL for Omics Analysis

This is the public placeholder for **SPaRTA** and **SPaRTA-Bench**, a benchmark of
7,500 verified question–SQL pairs over breast cancer, pancreatic cancer and melanoma
Xenium spatial-omics sections.

The code, benchmark data and fine-tuned models are being prepared in the main
SPARTA repository and will be pushed here after publication.

## Paper

Arka Dutta, Souvik Ghosh, Kenneth Prado, Ashiqur R. KhudaBukhsh, Hirak Sarkar.
*SPaRTA: Spatial Reasoning in Text-to-SQL for Omics Analysis.* Preprint, bioRxiv, 2026.
